# P06 / R08 快照评审

依据只读 REVIEW.md B-07：仅有 templateProgress.snapshot 的源码快照模板适用，普通固定模板不适用。设计稿与验收脚本未修改。

## 领域与执行

新增快照代码评审模板。创建时通过真实 Git 固定目标提交、增量基线、full/incremental 与 full/lightweight；库存是实际 Git blob 文件（含目标删除的基线文件），不是普通节点数。范围外、明确排除、未变更、符号链接、超限及已知二进制/锁文件各有明确排除原因。未跟踪文件与子模块外部工作树不在此仓库快照范围。

计划按文件单元分批，配置分析、独立复核与服务汇总步骤；源码工作区准备到固定 target SHA。轻量仅向有真实候选问题的单元派发独立复核，无候选步骤由服务显式跳过；全量复核每个已分析单元。职业仍采用已发布修订。

workspace.file.read 从 Git blob 读取，工作树或 HEAD 变化不会改读其他版本；服务记录尝试级完整读取凭据。snapshotUnits 提交必须匹配此节点的全部分配单元与 blob，未完整读取的文件、越界行号、重复单元/问题、遗漏或替换候选问题身份均拒绝。独立复核必须逐项提交 confirmed/rejected 和依据。服务汇总只消费成功尝试的结构化证据，记录实际已分析、未分析、待复核与排除范围；不会从步骤数推断文件分析数。

## 报告与界面

B-07 仅在快照绑定存在时出现。显示真实 mode/depth、固定版本、批次与输出目录。读取/重新读取报告不启动执行，取消后仍可读。每次读取生成 Markdown 文件和内容 hash，下载必须指向已读版本，并校验物理文件未被改动。前端读取失败或下载失败会清空旧正文，禁用下载；正文以安全的 React Markdown 标题/列表/行内代码呈现，不执行 HTML。阶段比例以源码文件单元计，未分析与待独立复核分别说明。任务完成后阶段区隐藏，最终服务汇总正文保存在最终步骤结果与本地记录。

## 验证口径

全仓 typecheck、Web production build 与 17 项快照领域/真实 Git/HTTP/模板/路由/任务 extras 回归通过。测试验证 Git refs 固定、工作树改动不污染读取、删除单元来源、无读凭据拒绝、候选身份校验、普通模板不适用、取消后可读/下载、报告文件篡改拒绝和旧 projection 回归。结构化分析证据明确标为 domain test fixture，用来检验聚合与校验，未冒充真实模型结果。

未做配置 opencode-go 的真实源码评审或 Electron 四主题视觉验收；因此本批没有新的真实模型结论。SQL/DB/PPT/知识域不包含在此批。已知读取限制：单文件256KB、仓库最多5000个 blob/删除单元；未知二进制内容读取失败时保留未完成状态，不伪造分析证据。
