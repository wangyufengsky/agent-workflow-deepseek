# P11 工具策略与数据库访问范围

本批依据只读设计 REVIEW.md §21、§22、B-13 与 tools.html、databases.html；不修改设计稿。

## 已落实

- 服务端工具清单、全局默认、项目继承/启用/停用、来源批停与回执；控制协议工具始终启用，禁用原因由服务给出。来源确认列出受影响工具，清单不完整时不能修改。
- 策略在实际 runSession 创建会话时冻结，并在每次受控调用与当前有效策略取交集。收紧/撤销立即生效，扩权不能扩大已创建会话。
- 数据库连接持久保存启用状态、绑定项目、允许 schema 与精确 schema.table 列表；未绑定项目不进入会话可发现连接，空 schema 禁止任务读取。职业能力、工具许可、节点声明与数据库授权同时满足才派发。
- 数据库查询读取会话冻结的原连接定义与版本化密码引用，后续编辑不会把旧会话悄悄切到新主机/新凭据。当前授权收紧仍立即阻止后续查询。
- SQL 资源守卫逐项检查 FROM/JOIN/逗号表引用/嵌套子查询，拒绝越 schema/表读取；不认识的 CTE、表函数、用户函数等保守拒绝。拒绝 dollar quotes 与反斜杠歧义，避免 PostgreSQL/MySQL 模式差异隐藏第二条语句或 COMMIT。
- MySQL 与 PostgreSQL 驱动每次查询都建立只读事务并回滚；PostgreSQL 单客户端按操作串行，避免并发事务串扰；不把缺失只读测量字段显示为已强制。
- 工具页面按来源列表展示单工具策略与项目三态；数据库页面可修改项目、schema/表范围与启停。保存响应丢失保留原请求号和表单，锁住重复写，仅核对原操作。
- 类型清单来自服务真实支持的 mysql2/pg 元数据，未提供驱动的历史类型只能查看，密码留空保留原版本。
- 补住工作区写入尚不存在的文件时经父目录 symlink 逃逸的问题：先解析最近存在祖先，再检验实际目标在工作区内。
