# 节点产物与运行内容 · 第一批

此批实现 P09 的文件产物与工具证据基础，不代表节点设计全状态已验收。

- `workflow.result.submit` 接受相对文件路径；服务检查当前任务/节点/尝试、冻结职业读取许可及工作区边界。普通文件最多8 MiB、一次32个，拒绝路径穿越与符号链接。提交时保存服务拥有的独立快照、修订与SHA-256；不会把原工作区后续变化当成旧产物。
- 精确任务/尝试/产物/修订/校验值读取，缺失、失效或损坏拒绝返回正文；文本预览前256 KiB，完整下载返回原文件。HTML/SVG以文本预览，不能执行产物中的脚本。
- 节点宽阅读区和运行内容页接通产物预览。运行分类实际使用`taskRunContent`；去掉“没有专用接口”的错误描述。工具活动保留真实参数、输出、错误及可用时间；保存前隐藏敏感字段，明确截断。
- Desktop IPC只接受产物身份，宿主决定服务地址并弹出保存对话框；核对返回身份与字节hash后保存，实际写入成功才返回saved。取消/校验失败/写失败不报已保存。浏览器用独立下载入口，不声称宿主已保存。
- 顺带补齐PPT archive/check/copy/restore/thumbnail与tools/policy共享路由，前端调用使用ROUTES。

## 第二批读取能力

- 工具证据落入现有SQLite调用JSON记录，不只留在回调内；按task/node/attempt/callId精确查询，参数/结果/错误分段读取，游标绑定调用记录修订。新版数据出现时拒绝把两版内容拼接。读取失败保留已加载工具内容，撤权/身份失效隐藏正文。
- 同一个callId后续状态在第一次出现的位置更新；同名工具不同callId保持独立，历史尝试加载时不再临时套用当前输出。
- 产物文本支持精确版本分段读取；共享阅读器使用react-markdown/remark-gfm呈现Markdown（禁用原始HTML和自动远程图片），JSON折叠树、原文行号/查找/自动换行/复制均接实际已加载内容。
- 9项针对性回归通过，含工具持久化、分段续读、修订漂移拒绝、跨任务/节点拒绝、晚回原位更新；类型检查/Web构建通过。尚未把这些离线与API证据记为全部GUI验收。

## 第三批：引用原文版本绑定

计划确认时保存需求输入快照，节点引用仅通过明确条目 ID 或完整相等文本绑定，不再按子串猜测。原文接口校验任务、节点、计划、条目、需求修订和快照摘要；历史计划没有快照时明确不可读，不借当前需求替代。新需求条目保留 CRLF/空白下的原文位置；有精确位置才展示全文定位，否则明确节选。阅读返回恢复会话滚动位置。

## 第四批：原生导出验收与 preload 修复

CUA 真实操作隔离 Electron 窗口时发现宿主桥缺失，产物只显示浏览器下载。构建将沙箱 preload 输出成 `.mjs`；依据 Electron 官方 ESM 文档（https://www.electronjs.org/docs/latest/tutorial/esm），沙箱 preload 不支持 ESM imports。现将源码保留 ESM、仅 preload 构建为 `preload.cjs`，main 保留 ESM，contextIsolation/sandbox 均保持开启。

修复后重新构建并在原生窗口操作：点击下载→macOS 保存对话框→取消→显示“已取消保存”；再次下载→选择隔离临时目录→保存→显示“产物已保存”。独立磁盘检查导出 119 字节，SHA-256 为 `fe038729b9b453a8311e5d540573bafd840f3a5b8993faf1e7eb457ab64ad0f7`，与提交快照一致。四主题均经界面按钮切换并留图，深色/浅色阅读和保存状态可见。证据 `docs/evidence/node-artifacts-2026-10-20/native-*.png`。

边界：这是离线夹具的真实原生文件读取/保存验收，没有调用模型；仍不代表所有节点阅读中间态或完整设计逐像素验收通过。
