# 设置、人工验收和知识中间态补齐（2026-10-20）

## 本批改动

- 默认模型从受管 OpenCode 的 `/provider` 读取已连接提供方的实际目录，仅投影 provider/model 与显示名称，不向 renderer 返回认证或 options。目录加载、未就绪、失败、空结果分别展示；保存后四种默认职责使用所选档案。
- 发布网络的多行 HTTP 主机列表保留编辑中的换行，在提交时归一化；Undici 响应头转为标准 Response 接受的键值对象。
- execution 明确返回当前人工验收 pending/rejected 投影。前端手动推进不再把“执行成功但尚未人工验收”当作前驱已完成；旧数据缺少验收投影时保守处理。
- 知识研究员抽屉消费当前实际运行状态、已发送问题和冻结角色证据。进行中不再显示“未发送”或误称没有工具调用；完成后才展示完整轨迹。
- 长请求首次读到进度后，按原 requestKey 读取操作回执。服务已确认 accepted 时，全局提示显示“已受理”，不因 HTTP 响应仍挂起而显示“发送中”。UNKNOWN 不重发。
