# 工具与 Skill 设计一致性补齐

依据只读设计 `originals/main/pages/tools.html`：300px来源侧栏、来源摘要与工具列表分卡、全局开关/项目三态、内置工具锁定、Skill目录+正文分栏与原文行号。

本次实现将原先长列表+源文弹窗替换为可搜索目录和同页阅读器；目录切换绑定文档ID，加载失败不展示上一正文；空正文明确提示。Markdown阅读隐藏YAML头信息，原文、复制与搜索保留完整原文。来源与刷新操作放到正式标题栏。页面颜色使用已有四主题变量。

设计107/123行和停用确认明确规定“只影响新建会话，运行中的会话保持原权限”。本轮此前P11代码把工具开关即时收紧用于运行中会话，与该权威冲突；本批纠正为冻结allowedTools，保留独立会话撤销、角色授权、执行身份及数据库即时权限检查。修改的是本轮新增开发回归测试中对应的错误预期，没有修改设计稿或验收脚本。4项HTTP权限回归通过，包含旧会话保持、新会话拒绝、新授权不能扩展旧会话及独立scope撤销。

CUA浏览器对隔离本地服务的真实操作：切Git来源、停用单工具后重新读取显示“全局停用”；Skill目录切换、空正文、Markdown阅读、完整源文与行号；四主题通过正式主题按钮切换留图。截图仅含临时测试资料，位于 `docs/evidence/tools-parity-2026-10-20/`。类型检查和Web构建通过。

范围边界：这些是浏览器GUI和实际HTTP/SQLite控制流证据，不是原生桌面全状态验收；外部MCP授权/清单未知、来源整体停用确认、项目继承及故障恢复还需逐态核对。没有把原型示例来源伪造成已连接来源。

补充：工具/Skill页签、来源、项目范围、Skill选中与目录搜索保存在页面URL；真实CUA选择review-fixture后刷新，仍显示同一Skill和主题。页面返回不依赖组件内临时状态。类型检查、Web构建通过。
